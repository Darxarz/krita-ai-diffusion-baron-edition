Krita AI Diffusion Baron Edition

Сборка 1.53.0-baron.3 для Krita 5 / Qt5. Модели и вычисления остаются на ComfyUI-сервере 192.168.50.191:8188.

Установка

  1. Сохрани открытые документы. Сделай резервную копию существующей папки %APPDATA%\krita\pykrita\ai_diffusion и её настроек.
  2. В Krita выбери Инструменты → Скрипты → Импортировать плагин Python из файла (Tools → Scripts → Import Python Plugin from File). Укажи ZIP Baron Edition.
  3. Перезапусти Krita. При необходимости включи плагин в настройках Python-плагинов.
  4. Подключись к своему серверу и обнови список моделей.

Плагин использует прежний идентификатор ai_diffusion: установка заменяет обычную версию. Этот архив подготовлен отдельно; установленный плагин пока не менялся. Автообновление из оригинального репозитория отключено, чтобы оно не затёрло Baron Edition.

Подключение к Оркестриону (Baron .3)

В настройках подключения появился отдельный вариант Orchestrion, рядом с официальным облаком. Для него нужны изменения сайта из ветки baron/krita-orchestrion в D:\orchestrion-baron-integration. Они подготовлены, но ещё не перенесены на работающий сайт. До обновления сайта пользуйся прежним подключением через Custom ComfyUI.

После обновления сайта:

  1. Выбери Orchestrion, укажи корневой адрес https://orchestrion.su.
  2. Нажми Войти через браузер. В Krita появится код.
  3. В открытой вкладке войди на свой сайт обычным способом. Если вход открывается в соседней вкладке, после него вернись на страницу подключения.
  4. Введи код из Krita и подтверди подключение. Плагин подключится автоматически.

Пароль в Krita не вводится и не сохраняется. Отдельный ключ устройства хранится в настройках в зашифрованном виде Windows; вход рассчитан на 30 дней. Кнопка Выйти отзывает этот ключ на сайте. Его также можно отозвать в кабинете среди API-ключей — карточка помечена Krita · Baron. Перенос настроек на другой компьютер потребует нового входа. Постоянный вход пока поддерживается только в Windows.

Баланс, цена и галерея

Стоимость и баланс показываются только в bleatbucks, по-русски — беелетиках. Пересчёта в деньги нет: цена покупки беелетиков зависит от выбранного пакета. Под кнопками генерации и апскейла показана предварительная цена всей пачки. Это оценка по разрешению и количеству результатов. Фактическое списание остаётся за сайтом после успешного результата и может отличаться из-за конечного размера. При недоступности цены плагин показывает сообщение, а не выдуманное число.

Галерея моделей показывает установленные модели и LoRA с поиском по имени и семейству. Картинки и слова активации берутся из метаданных сайта; без картинки показывается значок. Используются публичные превью CivitAI. Другие источники картинок пока не загружаются. Выбор создаёт отдельный пользовательский пресет; существующие пресеты сохраняются. Известные несовместимые семейства LoRA выбрать нельзя; для неизвестного семейства совместимость потребуется проверить самому. Слова активации видны в карточке и при необходимости добавляются в запрос вручную.

Как Qwen понимает референсы

Референс — это дополнительное условие для рисования. В нашем workflow картинка передаётся двумя путями: Qwen3-VL помогает понять её содержание вместе с твоей инструкцией, а VAE переводит внешний вид и структуру в данные для генератора. Модель рисует результат с учётом обоих условий. Простая вставка пикселей и обучение новой LoRA при этом не происходят.

При Edit основной холст становится первым изображением, дополнительные референсы идут за ним. При генерации без Edit первым становится первый подключённый референс. Нумерация определяется порядком отправки; название слоя само по себе не сообщает модели его назначение.

В запросе удобнее использовать <layer:Точное название слоя>. Плагин найдёт слой, подключит его как референс и заменит ссылку на нужный номер. Для Qwen 2.1 это маркер вида <image2>, для Krea — image 2. Не добавляй тот же слой ещё и вручную в список референсов: он будет отправлен дважды.

В Edit с обычными настройками Qwen исходник получает обозначение <image1>. Максимум — 10 изображений вместе с исходником, по документации автора модели: Qwen Image 2.1. Для начала обычно достаточно 1–3 референсов с понятными, разными ролями.

Как писать запрос

Укажи действие, источник каждой детали и то, что нужно сохранить. Описывай конкретные объекты: лицо, причёску, куртку, позу, фон, освещение. Слова «используй референс» дают модели меньше информации, чем «возьми только крой куртки; лицо и фон оставь из исходника».

Например, в Edit исходный портрет находится на холсте, а одежда — на слое Куртка:

Replace the jacket worn by the person in with the jacket from . Use that reference only for the jacket's cut, color and material. Preserve the person's face, hairstyle, pose, camera angle and original background. Match the jacket's lighting and perspective to the source photograph.

Смысл: «замени куртку, возьми из референса только крой, цвет и материал; сохрани лицо, причёску, позу, ракурс и фон; согласуй свет и перспективу». Пример дан на английском как готовая отправная точка; сравнительного теста качества русского и английского в этой сборке не проводилось.

Чтобы взять личность, но свободно изменить сцену:

Create a new portrait of the person from sitting in a cafe. Preserve the facial features and hairstyle. Change the pose and background to match the new scene. The person wears a navy jacket over a white shirt. Natural warm light, medium portrait.

Здесь можно выключить Edit: основой становится референс персонажа, а не холст.

Для одного лишь стиля:

Use only for the brushwork, color palette and paper texture. Paint an owl sitting on a tree branch. Use a new composition with one owl.

Назначай референсам разные задачи. Если один задаёт лицо, другой одежду, третий стиль, напиши это явно. Противоречивые референсы или указания «точно сохрани позу» одновременно с «совершенно измени позу» ухудшают управляемость. Даже хороший запрос не гарантирует точное сохранение каждой детали.

Qwen Image 2.1 в Baron Edition

Выбери Qwen Image 2.1 — Baron Edition, включи Edit, начни с 100% силы, 25 шагов Euler/simple и CFG 1. При этом отрицательный промпт не используется: «сохрани лицо», «фон остаётся прежним» и другие ограничения пиши в основном запросе.

100% в Edit означает полный процесс исполнения инструкции; сохранение исходника обеспечивают референсы. Снижение силы дополнительно привязывает результат к исходным пикселям, но может ослабить нужное изменение. Выделение в Krita ограничивает результирующий слой маской. В наших тестах после наложения слоя пиксели за пределами маски полностью совпали с исходными.

Для удаления фона явно попроси прозрачный фон. Workflow сохраняет альфа-канал дополнительных референсов. Проверены обычная правка, частичная сила, правка области и прозрачный результат на твоём сервере.

Krea 2

Базовая Krea 2 — генератор изображений. Для работы по инструкции сборка подключает твою Krea 2 Identity Edit v1.2, а также специальные узлы понимания референса и сохранения его внешности. Это соответствует механизму на твоём сайте.

Готовые стили:

| Стиль | Для чего | | --- | --- | | Krea 2 Turbo | Генерация без референсов, 8 шагов / CFG 1 | | Krea 2 Edit — Baron Edition | Правка и перенос персонажа, 10 шагов / CFG 1 | | Krea 2 Style Reference — Baron Edition | Перенос художественной манеры через отдельную LoRA | | Krea 2 Wulver — Baron Edition | Отдельный профиль Wulver: 14 шагов / CFG 1.5 |

Встроенный стиль нужно дублировать, чтобы менять настройки и выбирать другой чекпоинт. Общий механизм работает со всеми шестью обнаруженными Krea 2 моделями. Для них выполнен реальный тест редактирования портрета; это не полный тест всех возможных сюжетов и комбинаций LoRA.

При редактировании или подключении референсов автоматически выбирается Identity Edit R128, сила 1. Можно вручную добавить в стиль R64 или полную Identity Edit; тогда используется твой выбор. Оставляй включённым один её вариант. Другие совместимые персонажные LoRA можно добавлять поверх неё. При обычной генерации без референсов функциональная Identity Edit автоматически не добавляется.

Krea Identity Edit получает два изображения всего: в Edit это холст и один дополнительный референс. При генерации без Edit — два дополнительных референса. Порядок для двух картинок: сцена → персонаж. Подготовленный лист с несколькими видами персонажа занимает один слот, но это не независимое управление каждым лицом. Режим переноса стиля принимает до трёх картинок вместе с исходником.

Параметры стиля:

  • Reference purpose: identity — внешность и предметы; style — манера рисования. Workflow и функциональные LoRA у этих задач различаются.
  • Reference fidelity: начальное значение 4 для Edit. Попробуй 2–6, если нужно сильнее сохранить внешность. Усиление может также удерживать старую позу и фон. При генерации новой сцены сборка ограничивает значение единицей.
  • Reference detail: 768 — начальный баланс. 1024 можно пробовать для лица; 512 — если модель упорно сохраняет старую сцену. Больше не всегда лучше.

Эти рекомендации основаны на документации Identity Edit и настройках твоего сайта. Рисование по референсу ограничено примерно 2 мегапикселями, после чего результат подгоняется под холст. Для крупных работ лучше отдельное увеличение и правка лица в выделенной области. Очень маленькое лицо в общей сцене не может сохранить столько же деталей, сколько крупный портрет.

Удаление крупных объектов на Turbo бывает ненадёжным; автор Identity Edit предлагает для этого Raw и другой CFG. Твои чекпоинты без слова Turbo не считаются официальным Raw автоматически. В этой сборке не подключены региональные LoRA одновременно с Krea-референсами и правка с референсами при плиточном увеличении.

Отделить фон: отдельный режим Baron

В меню режимов рядом с генерацией и апскейлом выбери «Отделить фон». Установка этого обновления такая же: импорт ZIP и перезапуск Krita. Твой старый background remover 2 сохранён: новый режим использует отдельный workflow.

По умолчанию остаётся только персонаж, мебель относится к фону. Здесь два разных этапа: распознавание людей через установленный person_yolov8m-seg и уточнение мягкой маски через BiRefNet-HR-matting. Это не диффузионное перерисовывание: изображение не генерируется заново. Опция очистки цвета краёв оценивает цвет переднего плана и может менять RGB по контуру.

  1. Источник: видимый холст или активный слой/группа. Холст обрабатывается целиком: выделение не обрезает руки, ноги или волосы. За границами исходного холста деталей нет.
  2. Оставить только персонажа: включено для человека без стула, стола и прочей мебели. Распознаются все обнаруженные люди. На фоне с другими людьми маску может понадобиться поправить. Если нужен персонаж вместе с предметами, отключи эту опцию.
  3. Модель краёв: BiRefNet-HR-matting для мягких краёв; RMBG-2.0 — доступная альтернатива. BiRefNet_toonout предназначен для иллюстраций, но в этой сборке его качество отдельно не проверялось. Наличие в списке не означает, что веса уже скачаны.
  4. Отделить персонажа: появится группа со слоем персонажа и отдельной маской прозрачности. Можно выбрать маску и дорисовать белым пропущенные части, чёрным убрать остатки фона. Сам исходник не удаляется; по умолчанию он скрывается.
  5. Слой фона: создаётся скрытым и содержит пустое место вместо персонажа. Это отделение слоёв, а не восстановление невидимой части фона. Для заполнения этого места можно отдельно использовать Edit/дорисовку.

Если остались куски фона

Сначала уменьши запас для тонких деталей с 8 до 4 или 2 px. Большой запас сохраняет пряди, но может захватить соседнюю мебель. Не увеличивай размытие без необходимости: оно смягчает край, но не исправляет неправильно распознанный объект. Расширить / сузить край: отрицательное значение на 1–2 px убирает обводку, но сильное сужение съедает волосы. Если потеряна часть тела, сначала снизь порог распознавания с 0.3 до 0.2; это не гарантирует нахождение любого персонажа.

SAM — дополнительное уточнение контура, выключено по умолчанию. На нашем примере со стулом оно добавило маленький лишний фрагмент, поэтому не выбрано как основной режим. Если включаешь его, на сервере нужна соответствующая SAM-модель.

Режим «По описанию» использует GroundingDINO + SAM. На твоём сервере обнаружен узел Segment, но отсутствует Python-пакет groundingdino: этот вариант сейчас не работает. Зависимости сервера я не менял. Рабочий вариант по умолчанию использует уже установленный детектор людей. Для животных и необычных персонажей можно попробовать модель краёв без распознавания человека и поправить маску вручную; качество для этих случаев не подтверждено.

Первый запуск выбранной модели может скачать веса на сервер ComfyUI. В ходе проверки скачались BiRefNet-HR-matting и его служебные файлы в каталог моделей ComfyUI. Сайт Z:\orchestrator, его файлы и службы не менялись.

Копия улучшенного custom workflow

Если нужен прежний способ работы через Graph, импортируй ai_diffusion/workflows/background_remover_baron.json из папки плагина или исходников. JSON входит в архив. Это вариант «только персонаж» с параметрами порога, запаса для волос и очистки цвета края; он возвращает прозрачное изображение. Отдельный режим дополнительно создаёт редактируемую маску и слой фона.

Что проверено
